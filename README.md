# 烦恼雷达（Demand Radar）

一个本机运行的静态网页工具：将内容平台导出的笔记与评论 CSV 在浏览器本地聚合，帮助把模糊的“烦恼”整理成可继续验证的具体问题场景。

## 这版能做什么

- 查看按问题场景排序的机会卡片，例如收入与负债、求职焦虑、职场消耗、睡眠与情绪恢复等。
- 选择一对 MediaCrawler 导出的 CSV（笔记 + 评论），按 `note_id` 关联后在本机分析。
- 从主题卡片创建研究项目，记录假设、目标人群、证据、下一步与结论。
- 浏览器本地保存研究记录；不需要数据库或账号。

## 快速开始

### 方式一：双击启动（Windows）

双击 `启动烦恼雷达.cmd`，浏览器会打开：

```text
http://127.0.0.1:4174
```

### 方式二：命令行启动

需要已安装 Node.js 18 或更高版本。

```powershell
cd D:\DemandRadar
node serve.js
```

然后访问 `http://127.0.0.1:4174`。

## 导入 CSV

在“导入”页同时选择以下两类 CSV：

- 笔记文件：至少包含 `note_id` 和 `title` 或 `desc`，例如 `search_contents_*.csv`
- 评论文件：至少包含 `comment_id`、`note_id`、`content`，例如 `search_comments_*.csv`

页面会在浏览器内解析文件，以关键词将内容聚合到主题，并根据笔记量、评论量、评论点赞和笔记互动生成排序分数。

## 数据与隐私边界

- CSV 由用户自己提供；本项目不包含爬取、登录、绕过平台限制或规避风控的功能。
- 导入解析在本机浏览器中完成，原始 CSV 不会上传到本项目的服务端。
- 页面内置的是匿名聚合快照，不展示昵称、原始评论、访问令牌或带追踪参数的链接。
- 分类是关键词信号，不是平台全量统计，也不等同于独立用户人数。同一条内容可命中多个场景。
- “机会分”用于决定优先研究顺序，不代表市场规模、医学判断或投资建议。
